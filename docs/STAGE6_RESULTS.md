## 失败现象

- Task 4（橱柜抽屉中的碗）：两个回合没有形成有效的取出轨迹。
- Task 5（ramekin 上的碗）：策略能够接近或扰动物体，但没有完成稳定搬运。
- Task 7（炉子上的碗）：部分轨迹能将碗移动到盘子附近，但释放或稳定放置失败。
- Task 8（盘子旁的碗）：尽管源目标距离很短，两个初始状态仍失败，说明几何距离近不代表抓放可靠。

为保持与官方评测路径一致，保存的后处理动作没有额外裁剪。少量越界主要发生在夹爪维度，仿真器
能够正常接受，没有引发运行错误。
